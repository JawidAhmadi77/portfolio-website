# Design System — Portfolio Website

## Identity
- **Colours:** deep black background, gold accents, white text — a luxury, calm, expensive feel. Gold is used sparingly: headings rules, badges, buttons and hover states.
- **Typography:** large, confident headings; clean sans-serif body; generous line-height. Persian/Dari text uses full RTL layout with the same hierarchy.
- **Layout:** persistent top navigation, wide content column, card-based project grid, persistent footer. Mobile gets a burger menu and a single-column flow with no horizontal overflow.

## Project cards
Each project is presented the way it should be judged: its real dashboard screenshot, a one-line description, its tech tags and a direct WhatsApp contact button. No stock images, no invented statistics, no testimonials — only real work.

## Principles
1. Real screenshots only.
2. One obvious next action on every page (contact via WhatsApp).
3. Bilingual from the start — English and فارسی, switchable, with correct RTL.
4. Fast: a single self-contained page, no heavy frameworks.
